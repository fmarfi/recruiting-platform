# A-14 - Global search

**Priority:** Must  
**Requirement:** A-14 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want one search box across accounts, people and job orders with filters, so that I find anything in seconds.

## Acceptance criteria

1. **Cross-entity search**
   - Given an account "Atlas Retail", a person "Ayse Atlas" and a job order "Atlas Store Manager"
   - When the user searches "atlas"
   - Then results from all three types are returned, grouped by type
2. **Turkish characters**
   - Given a person named "Işıl Öztürk"
   - When the user searches "isil ozturk" and "Işıl"
   - Then both find her (diacritic- and case-insensitive)
3. **Filters**
   - Given mixed results
   - When the user filters by sector, status, owner and last-contact-before date
   - Then only matching records remain
4. **No results**
   - Given a term matching nothing
   - When the user searches
   - Then an empty state with a hint is shown, not an error
5. **Speed**
   - Given a data set of 10,000 records
   - When a search is run
   - Then results arrive in under 2 seconds (NFR-08)
6. **Permissions**
   - Given a consultant
   - When they search
   - Then they only see what their role may see

## Dependencies

A-01, A-06, A-12
