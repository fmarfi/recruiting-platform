# UX-04 - Pipeline board

**Priority:** Must  
**Requirement:** UX-04 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want a kanban board per job order with one column per stage, so that I see the whole search at a glance.

## Acceptance criteria

1. **Columns**
   - Given a job order
   - When its pipeline opens
   - Then columns SOURCED to PLACED and REJECTED appear in order with counts
2. **Cards**
   - Given an application
   - When it is shown
   - Then its card shows name, current company and title, and days in stage
3. **Move**
   - Given a card
   - When it is dragged to a legal column
   - Then the stage updates and persists after reload
4. **Rejection reason**
   - Given a card dragged to REJECTED
   - When it is dropped
   - Then a reason is requested; cancel returns the card
5. **Mobile**
   - Given a phone-width screen
   - When the board opens
   - Then columns scroll horizontally or collapse into a stage list, with a Move menu replacing drag
