# UX-07 - Consistent layout and languages

**Priority:** Should  
**Requirement:** UX-07 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a user, I want the same list, filter and detail patterns everywhere, in Turkish or English, so that the app is predictable.

## Acceptance criteria

1. **Language switch**
   - Given a user
   - When they choose Turkish
   - Then all labels, status names and messages are Turkish; no untranslated keys are visible
2. **Pattern reuse**
   - Given the account, job order and person lists
   - When they are viewed
   - Then filters sit in the same place, columns use the same sort control and row click opens the detail
3. **Date format**
   - Given Turkish locale
   - When a date is shown
   - Then it uses dd.MM.yyyy
