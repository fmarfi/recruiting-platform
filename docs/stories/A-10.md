# A-10 - Next actions and reminders

**Priority:** Should  
**Requirement:** A-10 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want next actions with owner and due date on my home screen, so that I never forget a follow-up.

## Acceptance criteria

1. **Create**
   - Given an account or person page
   - When the user adds a next action with text, owner and due date
   - Then it is saved as open
2. **Due date mandatory**
   - Given the next-action form
   - When the due date is empty
   - Then it is not saved
3. **Home screen**
   - Given the user has 2 due-today and 1 overdue next actions
   - When they open home
   - Then the overdue one is flagged and all three are listed, overdue first
4. **Complete**
   - Given an open next action
   - When the owner marks it done
   - Then it leaves the home list, keeps a completed date and appears in the timeline
5. **Only own on home**
   - Given actions owned by other users
   - When the user opens home
   - Then those are not shown (a manager can view a team member's list)
