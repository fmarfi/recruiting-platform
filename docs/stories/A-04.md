# A-04 - Activity log

**Priority:** Should  
**Requirement:** A-04 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want to log visits, calls, meetings, e-mails and notes on an account or a person, so that the relationship history is not lost.

## Acceptance criteria

1. **Log a call on an account**
   - Given an account page
   - When the user adds an activity of type CALL with date, short text and optional linked person
   - Then it appears at the top of the account's activity list and the timeline
2. **Log on a person**
   - Given a person page
   - When the user adds a NOTE
   - Then the note appears on the person page; if the person is a contact of an account it also shows on that account's timeline
3. **Types are closed**
   - Given the activity form
   - When a request uses a type other than CALL, VISIT, MEETING, EMAIL or NOTE
   - Then the request is rejected
4. **Last contact updates**
   - Given a person with last contact 1 Sep
   - When a CALL dated 10 Oct is logged for them
   - Then the person's last contact date becomes 10 Oct (and does not go backwards if an older date is logged)
5. **Edit window**
   - Given an activity written by a consultant
   - When another consultant tries to edit it
   - Then it is rejected; the author or a manager can edit, and edits are logged
