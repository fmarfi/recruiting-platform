# UX-06 - Quick add

**Priority:** Should  
**Requirement:** UX-06 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant on my phone after a client visit, I want to log a call, visit or note in under 30 seconds, so that I actually do it.

## Acceptance criteria

1. **Fast path**
   - Given an account or person page
   - When the user taps Quick add
   - Then a form with type, text and date (default now) is shown; saving needs at most 3 inputs (type, text, save)
2. **Measured**
   - Given a pilot user
   - When they log a visit on a phone
   - Then it takes under 30 seconds in the usability test (UX-10)
3. **Failed save**
   - Given the save fails (no network)
   - When the user taps save
   - Then the text is kept in the form and an error says to retry
