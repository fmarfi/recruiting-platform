# A-11 - CSV/Excel import

**Priority:** Could  
**Requirement:** A-11 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a manager, I want a one-off import of existing accounts and contacts, so that we do not retype our data.

## Acceptance criteria

1. **Valid file**
   - Given a CSV with columns name, sector, owner, contact name, contact e-mail
   - When an admin uploads it
   - Then accounts and contacts are created and a summary shows created, skipped and failed counts
2. **Bad rows**
   - Given a CSV with one invalid e-mail
   - When it is imported
   - Then that row is reported with its line number and valid rows are still imported
3. **Duplicates**
   - Given a row matching an existing account name
   - When it is imported
   - Then it is skipped and reported, not duplicated

A-01, A-03
