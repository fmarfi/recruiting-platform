# A-05 - Proposals

**Priority:** Should  
**Requirement:** A-05 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As an account manager, I want proposals on an account with commercial terms and a status, so that I can track what was offered and answered.

## Acceptance criteria

1. **Create a draft**
   - Given an account
   - When the user creates a proposal with title, fee model and terms
   - Then it is saved in status DRAFT
2. **Send**
   - Given a DRAFT proposal
   - When the user changes it to SENT
   - Then the status changes, the sent date is stored and terms become read-only
3. **Reject needs a reason**
   - Given a SENT proposal
   - When the user marks it REJECTED with no reason
   - Then the change is rejected; with a reason it succeeds
4. **Accepted is final**
   - Given an ACCEPTED proposal
   - When a user tries to change its status
   - Then the change is rejected
5. **Terms locked after send**
   - Given a SENT proposal
   - When a user edits the commercial terms
   - Then the edit is rejected
