# UX-02 - Three clicks and global search

**Priority:** Must  
**Requirement:** UX-02 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want to reach any record in three clicks or fewer and search from every screen, so that I never get lost.

## Acceptance criteria

1. **Search everywhere**
   - Given any screen
   - When the user looks at the header
   - Then the global search box (A-14) is present
2. **Three clicks**
   - Given home
   - When the user wants a given job order's pipeline
   - Then it can be reached in at most three clicks (account, job order, pipeline), checked by walking the flows of the 6 core screens
3. **Keyboard**
   - Given any screen
   - When the user presses "/"
   - Then focus moves to the search box
