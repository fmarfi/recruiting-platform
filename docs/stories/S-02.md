# S-02 - Website form consent

**Priority:** Must  
**Requirement:** S-02 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a candidate applying on the website, I want to read the KVKK notice and give consent through a separate, unticked checkbox, so that I stay in control.

## Acceptance criteria

1. **Notice visible**
   - Given the application form
   - When it loads
   - Then the information text (or a link and summary) is shown in Turkish and English
2. **Unticked by default**
   - Given the form
   - When it loads
   - Then the consent checkbox is not ticked and is separate from other checkboxes
3. **Cannot submit without consent**
   - Given the checkbox unticked
   - When the candidate submits
   - Then the submission is rejected with a clear message and nothing is stored
4. **Consent stored**
   - Given the box ticked
   - When the form is submitted
   - Then the person is stored with consent GIVEN, text version, timestamp and channel WEBSITE
