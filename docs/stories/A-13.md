# A-13 - Network links

**Priority:** Should  
**Requirement:** A-13 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want to record who knows whom and who introduced whom, and see a person's or company's connections, so that I can find the shortest route to someone.

## Acceptance criteria

1. **Create a link**
   - Given two persons
   - When the user links them with type KNOWS, WORKED_WITH, INTRODUCED, REFERRED or REPORTS_TO and a note (KNOWS and WORKED_WITH are symmetric; the others have a direction from one person to the other)
   - Then the link appears on both person pages
2. **No self link**
   - Given a person page
   - When a user links the person to themselves
   - Then it is rejected
3. **Connections view**
   - Given a person with 4 links
   - When their page is opened
   - Then the 4 connected people are listed with link type and a click leads to each
4. **Company connections**
   - Given several persons currently at one company
   - When the company's connections view is opened
   - Then those people and their links to our network are shown
5. **Remove**
   - Given an existing link
   - When a user deletes it
   - Then it disappears from both pages and the deletion is logged
