# A-06 - Job orders

**Priority:** Must  
**Requirement:** A-06 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want job orders inside an account with role details and a status, so that I can track every search for a client.

## Acceptance criteria

1. **Create a job order**
   - Given an account that is not CLOSED
   - When the user creates a job order with title, location, seniority and description
   - Then it exists in status OPEN under that account
2. **Not under a closed account**
   - Given a CLOSED account
   - When a user creates a job order
   - Then it is rejected
3. **Advance the status**
   - Given a job order in OPEN
   - When a consultant moves it to SOURCING
   - Then the status changes and the change is logged with user and time
4. **Illegal move**
   - Given a job order in OPEN
   - When a user moves it to OFFER
   - Then the change is rejected
5. **Cancel needs a reason**
   - Given a SOURCING job order
   - When the user cancels it without a reason
   - Then it is rejected; with a reason it becomes CANCELLED
6. **Fill needs a placement**
   - Given a job order in OFFER with no candidate in PLACED
   - When the user sets FILLED
   - Then it is rejected; after one application is PLACED it succeeds
7. **Days open**
   - Given a job order created 12 days ago and still open
   - When its page or card is displayed
   - Then it shows "12 days open"; for FILLED or CANCELLED the count stops at the closing date
