# UX-03 - Status badges and one-click change

**Priority:** Must  
**Requirement:** UX-03 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want statuses as coloured badges that I can change with one click or by drag and drop, so that updates are effortless.

## Acceptance criteria

1. **Badge everywhere**
   - Given an account, proposal, job order and application
   - When they are shown in a list or detail
   - Then each has a badge with the label in the user's language and a colour per status
2. **Colour is not alone**
   - Given a badge
   - When it is viewed by a colour-blind user
   - Then the text label is always visible (not colour-only)
3. **One-click change**
   - Given an account in LEAD
   - When the user opens the badge menu
   - Then only legal next statuses are offered for the user's role, and picking one applies it
4. **Reason prompt**
   - Given a move that needs a reason
   - When the user picks it
   - Then a short dialog asks for the reason before the change is sent
5. **Drag and drop**
   - Given a pipeline board
   - When a card is dropped on a legal column
   - Then the stage changes; dropped on an illegal one it snaps back with a message
