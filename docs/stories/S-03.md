# S-03 - Retention and deletion

**Priority:** Must  
**Requirement:** S-03 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As the data protection officer, I want data flagged and then deleted or anonymised at the end of the retention period, so that we do not keep CVs longer than allowed.

## Acceptance criteria

1. **Flagging**
   - Given a retention period of 2 years and a person whose clock started 23 months ago
   - When the nightly job runs
   - Then the person is flagged "retention ending" and the owner is notified
2. **Delete or anonymise**
   - Given a flagged person with no renewed consent
   - When the period ends
   - Then the personal fields are anonymised (or the record deleted per policy), pipelines keep non-personal facts, and the action is written to the audit log
3. **Renewal**
   - Given a flagged person
   - When consent is renewed
   - Then the flag is cleared and the retention clock restarts
4. **Configurable**
   - Given an admin
   - When they change the period to 18 months
   - Then the new value applies to the next run and the change is logged
5. **Time-shifted test**
   - Given test data dated 25 months back
   - When the job runs in a test with a fixed clock
   - Then those records are processed and newer ones are not
