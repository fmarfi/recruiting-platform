# UX-08 - Guided empty states

**Priority:** Should  
**Requirement:** UX-08 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a new user, I want to be told what to do first on empty screens, so that I am not stuck.

## Acceptance criteria

1. **No accounts**
   - Given no accounts exist
   - When the accounts list opens
   - Then it shows "Add your first client" with a button to create one
2. **No job orders**
   - Given an account with none
   - When the job orders tab opens
   - Then a prompt to add the first job order is shown
3. **Empty search**
   - Given a search with no result
   - When results are shown
   - Then a helpful hint and a clear-filters action appear
