# UX-05 - Account page in one view

**Priority:** Must  
**Requirement:** UX-05 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want an account page with header, tabs and a side timeline, so that I find everything about a client in one place.

## Acceptance criteria

1. **Header**
   - Given an account
   - When the page opens
   - Then name, status badge and owner are visible in the header
2. **Tabs**
   - Given the account page
   - When it opens
   - Then tabs for contacts, job orders and proposals are present with counts
3. **Timeline side**
   - Given the account page
   - When it opens on a laptop
   - Then the timeline (A-08) is visible beside the tabs; on a phone it moves below
4. **Deep link**
   - Given a URL to the job orders tab
   - When it is opened
   - Then that tab is selected

## Dependencies

A-01, A-03, A-05, A-06, A-08
