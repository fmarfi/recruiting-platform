# UX-09 - Responsive layout

**Priority:** Should  
**Requirement:** UX-09 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want to use the app on laptop and phone, so that I can work after meetings.

## Acceptance criteria

1. **Phone width**
   - Given a 390 px wide viewport
   - When any core screen opens
   - Then there is no horizontal page scroll, text is readable and tap targets are at least 44 px
2. **Laptop width**
   - Given a 1366 px viewport
   - When the account page opens
   - Then the two-column layout is used
3. **Navigation**
   - Given a phone
   - When the menu is used
   - Then all six core screens are reachable
