# UX-01 - Home: My day

**Priority:** Must  
**Requirement:** UX-01 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a consultant, I want a home screen with my next actions, overdue follow-ups, recent accounts and open jobs, so that I know what to do first.

## Acceptance criteria

1. **Content**
   - Given a user with 2 next actions, 1 overdue, and recent work
   - When they sign in
   - Then the home screen shows next actions (overdue flagged), recent accounts and open jobs on one screen, the first five of each without scrolling on a laptop
2. **Empty state**
   - Given a new user with no data
   - When they open home
   - Then a guided prompt is shown (see UX-08)
3. **Click-through**
   - Given an item on the home screen
   - When the user clicks it
   - Then they land on the right record page
