# UX-10 - Usability test with pilot users

**Priority:** Should  
**Requirement:** UX-10 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As the product team, I want 3-5 pilot consultants to complete the core tasks unaided before release, so that we know the UI works.

## Acceptance criteria

1. **Task success**
   - Given 3 to 5 pilot consultants
   - When they are given the tasks add a client, change a status, move a candidate
   - Then at least 80 percent of task attempts are completed without help, and the results are recorded
2. **Findings triaged**
   - Given the test is done
   - When results are reviewed
   - Then each issue is logged and triaged as fix now, later or won't fix before Gate 2

## Dependencies

All Must UX stories, working build

## Open questions

Who are the pilot consultants and when are they available? Success threshold (80 percent is ASSUMPTION).
