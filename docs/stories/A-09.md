# A-09 - Account dashboard

**Priority:** Should  
**Requirement:** A-09 in `docs/requirements.md`  
**Status:** Proposed (until the client validates)

## User story

As a manager, I want per-account figures (open jobs, candidates per stage, days open, next action), so that I can see where attention is needed.

## Acceptance criteria

1. **Open jobs count**
   - Given an account with 3 open and 2 closed job orders
   - When the dashboard is shown
   - Then "Open jobs: 3"
2. **Candidates per stage**
   - Given applications in several stages
   - When the dashboard is shown
   - Then a count per stage is shown for active applications (REJECTED shown separately)
3. **Days open**
   - Given an open job order
   - When the dashboard lists it
   - Then it shows days since creation
4. **Next action**
   - Given an account with two open next actions
   - When the dashboard is shown
   - Then the one with the earliest due date is shown, with owner
5. **Empty account**
   - Given an account with no job orders
   - When the dashboard is shown
   - Then zeros and an empty-state hint, no error
